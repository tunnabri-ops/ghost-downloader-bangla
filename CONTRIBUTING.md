# Contributing to Ghost Downloader Bangla
Thanks for helping! Short guide:
- Fork the repo and create a branch for your change.
- Keep the Bangla-first UI: any new text should have a Bangla label.
- Test before you submit: web (open web/index.html and try a sample link), Python (python3 -m py_compile app.py downloader.py), desktop (node --check on main.js, preload.js, renderer/renderer.js).
- Open a pull request with a short description of what changed and how it was tested.
